Textbooks
======

[Gravity: An Introduction to Einsteins General Relativity](https://ia800402.us.archive.org/16/items/JBHartleGravityAnIntroductionToEinsteinsGeneralRelativityAddisonWesley20031/J%20%20B%20Hartle-Gravity%20_%20an%20introduction%20to%20Einstein%27s%20general%20relativity-Addison-Wesley%20%20%282003%29%20%281%29.pdf)
This is a great textbook if you are starting to learn general relavitiy (GR). This in one of the textbooks that I used when sitting in on classes at UChicago.

[Effective Computation in Astrophysics](https://lilith.fisica.ufmg.br/~dickman/transfers/comp/textos/Effective%20Computation%20in%20Physics%20(Python).pdf)
This book takes you through git, python and its basic packages (numPy and SciPy) all the way to remote version control and parallel computing. would also recommend this for any computer science student.

[Modern Quantum Mechanics - Sakurai](https://natural-universe.net/nu-docs/jon-science-bak/physics/QM/Modern_Quantum_Mechanics_Sakurai.pdf)
This is the standard textbook for graduate quantum mechanics.
